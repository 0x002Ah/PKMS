# Claude Code adapter for the local PKMS root

This file is a **template**.
Copy it to `~/PKMS/CLAUDE.md`.
It is the Claude Code-specific adapter; it is **not** the primary contract.

The primary contract is `~/PKMS/AGENTS.md`, derived from
`software/system/templates/local-root-AGENTS.md`.
Read that file first; everything in it applies to Claude Code as well.

## What Claude Code does here

- When operating from the local PKMS root, follow `~/PKMS/AGENTS.md` for
  operating modes, privacy boundaries, and general rules.
- For software tasks inside `software/`, additionally follow
  `software/AGENTS.md` (repo-level rules) and `software/CLAUDE.md`
  (Claude Code-specific repo rules).
- If anything here ever conflicts with `~/PKMS/AGENTS.md`, the AGENTS
  file wins.
